# simple_data_ware_house_project
Building a sample data ware house using SQL server

# SQL Server Bronze Layer

This project demonstrates the Bronze Layer of a data warehouse using SQL Server and SSMS.

### Features
- Created six tables to store raw CRM and ERP data.
- Loaded CSV files using `BULK INSERT`.
- Automated data loading using a stored procedure.
- Implemented error handling and execution-time tracking.
- Used `TRUNCATE TABLE` to prevent duplicate data during full reloads.

### Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL
